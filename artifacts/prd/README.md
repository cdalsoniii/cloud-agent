# Formal PRD planning packs

Generated by `npm run prd:plan` / Mastra tool `formal-prd-plan`.

Each run writes:

```
artifacts/prd/<slug>/
  00-REQUEST.md
  01-CONTEXT_BUNDLE.json
  02-ANALYSIS.md
  03-ISSUE_BACKLOG.md
  03-issues.json
  04-PRD.md
  05-SPECS/
  06-MILESTONES.md
  06-milestones.json
  07-jobs.json          # when --write-jobs
  meta.json
```

Pack directories (except this README) are gitignored. See `docs/formal-prd-planner.md`.
